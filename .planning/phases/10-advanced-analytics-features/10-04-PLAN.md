<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API /predict | Prediction requests may contain crafted features to game the model |
| ML Training Job → Database | Training reads 30 days of analytics_events (trusted internal data) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-15 | Tampering | Prediction feature manipulation | low | accept | Features extracted from database events (user cannot directly manipulate), only conversationId accepted in request |
| T-10-16 | Information Disclosure | GET /predict reveals escalation patterns | medium | mitigate | Require operator role authentication (reuse existing auth guards) |
| T-10-17 | Denial of Service | Training job CPU exhaustion | medium | mitigate | Limit training dataset to 10,000 conversations max per RESEARCH.md pitfall #4 (L1086-1098) |
| T-10-18 | Information Disclosure | Model weights expose training data patterns | low | accept | Model files stored server-side only (not exposed via API) |
| T-10-19 | Denial of Service | Inference requests flood | high | mitigate | Rate limit /predict/outcome to 100 requests/min per session (use existing throttler) |
</threat_model>
