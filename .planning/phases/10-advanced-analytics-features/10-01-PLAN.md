## Trust Boundaries

| Boundary | Description |

| API → Anthropic | User message text sent to external LLM (untrusted third-party) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Information Disclosure | IntentClassificationService.classifyIntentsBatch | medium | mitigate | Redact PII from message text before sending to Anthropic (regex strip phone/email/CPF) |
| T-10-02 | Denial of Service | Intent classification hourly job | medium | mitigate | Rate limit batch size to 100 messages/hour max (prevent API quota exhaustion) |
| T-10-03 | Spoofing | POST /intents/taxonomy | high | mitigate | Require operator role authentication (reuse existing auth guards from Phase 6) |
| T-10-04 | Tampering | Intent taxonomy injection | low | accept | Input validation via class-validator on IntentTaxonomyDto (intent_name max 100 chars, no SQL injection via parameterized queries) |
