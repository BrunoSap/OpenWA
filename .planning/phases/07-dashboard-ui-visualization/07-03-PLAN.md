<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Analytics API | SPA CRUD/export requests cross into the OPERATOR-gated analytics API |
| Alert rule config → dispatcher | notification_channels (e.g. slack webhook URL) supplied via UI is stored and later called server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-08 | Elevation of Privilege | non-operator hitting analytics CRUD/export | high | mitigate | Server-side @RequireRole(OPERATOR) on all endpoints; asserted by analytics-dashboard-auth.e2e-spec.ts |
| T-07-09 | Server-Side Request Forgery | slack webhookUrl in notification_channels | medium | mitigate | Reuse existing webhook SSRF guard (Phase 1 postWebhookPayload) server-side; UI does not bypass it |
| T-07-10 | Information Disclosure | export file contains chatId/userId | medium | mitigate | Export gated to OPERATOR role; download is user-initiated over authenticated fetch |
| T-07-11 | Tampering | XSS via conversation_id / rule name in table cells | low | accept | React auto-escapes text content in JSX |
</threat_model>
