<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Grafana → OpenWA API | Grafana JSON datasource crosses into the analytics API carrying OPERATOR credentials |
| Operator → Grafana UI | Admin authenticates to Grafana with GF_SECURITY_ADMIN_PASSWORD |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Information Disclosure | OPERATOR_API_KEY in datasource config | high | mitigate | Store in secureJsonData (encrypted at rest by Grafana), never in plaintext jsonData; supplied via env var not committed |
| T-07-02 | Elevation of Privilege | Grafana anonymous access | medium | mitigate | GF_AUTH_ANONYMOUS_ENABLED not enabled; admin password required |
| T-07-03 | Spoofing | Grafana port exposed publicly | medium | accept | Bound to host per compose; production must front with TLS/reverse proxy (documented in SETUP) |
| T-07-SC | Tampering | GF_INSTALL_PLUGINS simpod-json-datasource | high | mitigate | Plugin is Grafana-signed community plugin (grafana.com/grafana/plugins/simpod-json-datasource); pinned via official install mechanism |
</threat_model>
