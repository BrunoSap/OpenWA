<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WhatsApp webhook -> MessageService | Untrusted inbound message content and sender JID crosses into persistence |
| Service query -> DB | userId/limit values reach the recall query |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | recall query in conversation-memory.service.ts | high | mitigate | Use TypeORM repository `find({ where })` / parameterized query builder only; never string-interpolate userId or limit into SQL |
| T-05-02 | Information Disclosure | getRecentMessages scoping | high | mitigate | Query filters on the caller-supplied userId column; a missing/empty userId returns an empty result, never all rows |
| T-05-03 | Denial of Service | unbounded `take` | medium | mitigate | Clamp `limit` to a hard max (1000) inside the service before querying |
</threat_model>
