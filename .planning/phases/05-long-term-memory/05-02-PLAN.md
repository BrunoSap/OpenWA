<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API client -> MemoryController | userId/conversationId path+query params and pagination cross from an authenticated caller |
| Summarization job -> summaries table | job-supplied summary text and counts are written |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Information Disclosure | GET /history and /context endpoints | high | mitigate | Endpoints scope strictly on the userId path param and sit behind the existing ADMIN/OPERATOR api-key guard; no query returns cross-user rows |
| T-05-05 | Input Validation | history pagination + userId param | medium | mitigate | Validate userId/conversationId with class-validator DTOs; clamp `take` to max 100, `skip` >= 0 |
| T-05-06 | Denial of Service | summarization job | medium | mitigate | Dedup jobs by jobId=userId:conversationId; skip when fewer than 10 old messages; cap summary input message count |
| T-05-07 | Tampering | summaries upsert | low | mitigate | Unique constraint on (userId, conversationId); upsert not insert to prevent duplicate/conflicting rows |
</threat_model>
